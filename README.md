# Portfolio 95 - Windows 95 WebOS

A nostalgic Windows 95-style portfolio built with HTML, CSS, and JavaScript.

## 🖥️ Live Demo

[View Live Site](https://yourusername.github.io/web95os/)

## Features

- **Boot Sequence**: Authentic Windows 95 boot experience with POST screen
- **Desktop Environment**: Fully functional Windows 95 desktop with draggable windows
- **Apps Included**:
  - 🖥️ My Computer - File explorer with project showcase
  - 📧 Contact - Contact form
  - 💻 MS-DOS Prompt - Interactive terminal
  - 🎮 Pong - Classic Pong game
  - 💣 Minesweeper - Classic Minesweeper game
  - 🌐 Internet Explorer - Favorites showcase
  - 🔒 Secrets.txt - Easter egg content
  - 🗑️ Recycle Bin - Empty (0 bugs!)
- **BSOD**: Blue Screen of Death easter egg
- **Clippy Assistant**: Helpful office assistant
- **CRT Effects**: Authentic scanline overlay

## Tech Stack

- HTML5
- CSS3 (Windows 95 styling)
- Vanilla JavaScript

## Deployment

This site is hosted on GitHub Pages.

### Deploy to GitHub Pages:

```bash
# Initialize git (if not already done)
git init
git add .
git commit -m "Initial commit"

# Add your remote and push
git remote add origin https://github.com/yourusername/web95os.git
git branch -M main
git push -u origin main
```

Then enable GitHub Pages in repository settings:
1. Go to Settings → Pages
2. Select "main" branch as source
3. Your site will be live at `https://yourusername.github.io/web95os/`

## Local Development

Simply open `index.html` in a browser, or use a local server:

```bash
# Python
python -m http.server 8000

# Node.js
npx serve
```
