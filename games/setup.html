Freedoom Setup Instructions

🎮 Freedoom Setup for web95os

⚠️ Important: The JS-DOS CDN is blocked in your region. Follow these steps to manually download Freedoom.

Step 1: Download Freedoom JS-DOS Bundle

Download from one of these sources:

  1. GitHub (Recommended):
    https://github.com/freedoom/freedoom/releases
  2. Official Site:
    https://freedoom.github.io/download.html

Step 2: Create JS-DOS Bundle

The easiest way is to use a pre-made JS-DOS Doom bundle:

  1. Download: doom.zip from js-dos CDN
  2. Try this direct link: Download doom.zip
  3. Rename to freedoom.zip
  4. Place in web95os/games/freedoom.zip

Step 3: Verify Setup

Your folder structure should look like:

  • web95os/
    • games/
      • freedoom.zip ← The game file
    • js/doom.js
    • index.html

Step 4: Test the Game

  1. Open index.html in your browser
  2. Click the 👹 Freedoom desktop icon
  3. Click Start Game
  4. Enjoy playing!

🎮 Controls

  • Arrow Keys - Move / Turn
  • CTRL - Shoot
  • SPACE - Open doors
  • ESC - Menu / Pause
